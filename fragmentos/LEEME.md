# Fragmentos para copiar y pegar

Cada archivo `paso-XX-devcontainer.json` es **cómo debe quedar `.devcontainer/devcontainer.json`
completo al terminar ese paso**.

- Úsalos para **comparar** tu archivo línea a línea con el correcto.
- Si te pierdes o el entorno no arranca, puedes **copiar el archivo completo del paso**
  y pegarlo sustituyendo todo el contenido de tu `devcontainer.json`.
  Anótalo en `docs/entorno.md` («en el paso X usé el fragmento completo»): no resta nota
  si explicas qué había fallado.

| `paso-05-devcontainer.json` | Paso 5 · JupyterLab añadido |

| `paso-18-devcontainer.json` | Paso 18 · Versión de Java fijada |
